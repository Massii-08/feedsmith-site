# Feedsmith — marketing + SEO site

A **static** marketing and SEO site for **Feedsmith**, a freelance service that builds and
maintains **reliable data feeds from public sources** (factual, non-PII data — you operate
and own the data; we respect robots.txt and rate limits).

The brand is **faceless**: no person, no photo. Professional, confident, concrete.

## Stack

- Pure **HTML5** + **one** CSS file (`/css/style.css`).
- **No build step**, no JS framework. (Tiny inline vanilla JS only if ever truly needed — none required for v1.)
- **Zero external requests**: the two typefaces (Archivo, IBM Plex Mono) are self-hosted in `/fonts/`.
- Deploys **as-is** to **Cloudflare Pages**.
- All internal links are **absolute root-relative** (`/css/style.css`, `/offers/…`, `/de/`, …) because the site is served from the root.

## Structure

```
/                         Home (EN)
/de/  /fr/  /it/          Localized home pages (native DE / FR / IT copy)
/offers/*.html            The 4 offers (EN)
/guides/*.html            The 3 guides (EN)
/scrape/<slug>.html       pSEO landing pages (generated — see below)
/css/style.css            The single stylesheet (design tokens + class contract)
/fonts/*.woff2            Self-hosted Archivo + IBM Plex Mono (latin + latin-ext)
404.html                  Branded not-found page
robots.txt                Allow all + Sitemap reference
sitemap.xml               Home + localized + offers + guides
_headers                  Cloudflare Pages security headers
_redirects                Cloudflare Pages redirects (minimal)
```

## Preview locally

No build needed. From the site root:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>. (Use a server, not `file://`, so the absolute
root-relative paths like `/css/style.css` resolve correctly.)

## Deploy to Cloudflare Pages

1. Push this folder to a Git repo and connect it in the Cloudflare Pages dashboard
   (or use `wrangler pages deploy`).
2. **Build command:** *(none — leave empty)*
3. **Build output directory:** the repo **root** (`/`).
4. Cloudflare Pages automatically applies `_headers` and `_redirects`.

## pSEO generator (scrape landing pages)

The `/scrape/<slug>.html` programmatic-SEO landing pages are generated by a script:

```bash
python3 tools/generate_scrape_pages.py
```

After generating new pages, **add their `<url>` entries to `sitemap.xml`**
(there is a comment marking where the `/scrape/<slug>.html` entries go).

## Swap the placeholder domain

The canonical / Open Graph / sitemap / robots base domain is a **placeholder**:
`https://feedsmith.net`. When the real domain is known, replace it everywhere:

- `<link rel="canonical">`, `og:url`, and `hreflang` alternates in **every** HTML page
  (incl. `/de/`, `/fr/`, `/it/`, `404.html`).
- `Sitemap:` line in **`robots.txt`**.
- Every `<loc>` and `hreflang` `href` in **`sitemap.xml`**.

A quick find-and-replace of `https://feedsmith.net` across the repo covers all of them.

## Wire the contact form

Every contact form uses the **"Get a free feasibility check"** CTA with fields
`target_url`, `details`, `email`. The form `action` is a **placeholder**:

```html
<form action="https://formspree.io/f/mpqelldw" method="POST">
```

To activate it, pick one:

- **Formspree:** create a form, then set your Formspree form id (currently `mpqelldw`) in the form `action` of
  **every** page's form `action`.
- **Upwork invite (early on):** instead of a form service, point people to your Upwork
  profile / job invite. A visible `mailto:hello@feedsmith.net` fallback is already present
  under each form.

(Each form is marked with an HTML `<!-- TODO -->` comment at the `action`.)

## Legal-safe note

This service works with **public sources only** and **factual / non-PII data**. Wording
across the site stays on the right side of the line: *public sources*, *factual / non-PII
data*, *you operate and own the data*, *respect robots.txt and rate limits*. We never frame
the work as bypassing, breaking, evading, or defeating protections — the value is
**reliability on public data**.

For the pSEO `/scrape/*` pages, use **safe verticals only** — exclude anything involving
social networks, personal data / PII, or login-gated content.
