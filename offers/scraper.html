The deliverable here is engineered for reliability on exactly those public pages: it loads dynamic content properly, respects the source, and produces the same clean result run after run.

Scope & ground rules

  • Public sources only. The scraper targets public, logged-out pages and collects factual, non-PII data.
  • Respectful collection. It honours robots.txt and applies sensible rate limits so the source stays healthy.
  • You operate and own the data. You run the scraper on your infrastructure; the code and the output are yours.
  • Reliability, not circumvention. The goal is dependable access to data that's already public — nothing gated, private, or behind a login.
